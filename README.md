A program that writes one deadpan weather forecast for a city that does not
exist to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

Run it:

```sh
python3 main.py
```

The entry is a single line of 138 characters, inside the 1–160 character
gate, in the flat voice of a TV meteorologist who has seen it all:

> Tonight in Quillwick, minus 2, and the frost writes the same rude word on every windscreen, including the vicar's. Especially the vicar's.
